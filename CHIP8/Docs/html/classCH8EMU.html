Detailed Description

The CH8EMU class represents the complete CHIP-8 emulator. It inherits from CH8COM (common communication interface) and contains instances of all the major components: bus, CPU, PPU, keyboard, APU, and disk (ROM loader). It also manages timing for frames per second (FPS) and updates per second (UPS).
