Detailed Description

Declaration of the CH8COM abstract base class, which defines the common interface for all CHIP-8 hardware components.

This class provides a standardized interface that all hardware components (CPU, memory, PPU, etc.) must implement. It includes methods for power management, reset, and communication via the system bus.
