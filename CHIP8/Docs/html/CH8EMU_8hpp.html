class  CH8EMU
 The CH8EMU class represents the complete CHIP-8 emulator. It inherits from CH8COM (common communication interface) and contains instances of all the major components: bus, CPU, PPU, keyboard, APU, and disk (ROM loader). It also manages timing for frames per second (FPS) and updates per second (UPS). More...

Detailed Description

Declaration of the CH8EMU class, which represents the entire CHIP-8 emulator system.

This class composes all the subsystems (BUS, CPU, PPU, KEY, APU, DSK) and coordinates their operation through a main loop that handles timing and synchronization.
